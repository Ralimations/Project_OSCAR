What is O.S.C.A.R.?

A fully offline agentic system that transforms a constrained computer into a multimodal interactive hub without relying on cloud services.


  • 🔒 Offline-First: Runs entirely without cloud APIs. Privacy is mathematically guaranteed.
  • 💻 Constraint-Resilient: Engineered specifically for typical hardware like Intel i3, 16GB RAM, and 0 GPUs.
  • 🌐 Sensory Aware: Fuses Vision (Camera), Audio (Mic), and Desktop UI context natively into a single reasoning loop.

The Core Subsystems (1/2)

🧠

BRAIN (Planner)

Local OpenVINO LLM / Gemma 4 (4-bit GGUF). Employs deterministic fallback planning and routes intense tasks to external edge AIBOX hardware.

👁️

EYES (Vision)

Continuous MediaPipe Tasks Hand & Face Tracking. Native understanding of nods, head shakes, vertical scrolling, and pinch-to-click gestures.

The Core Subsystems (2/2)

👂

EARS (Hearing)

Offline Acoustic processing using OpenWakeWord & Faster-Whisper tiny to instantly transcribe voice commands into actionable pipelines.

⚡

VOICE & ACTION

Piper TTS for responsive local speech synthesis paired with PyAutoGUI & deep active-window macros for direct, zero-delay desktop maneuvering.

AGENTIC REASONING

GenAI: The Local Brain

Powering the "Brain" module with high-speed, local LLM execution:

  • ⚡ Llama 3.2 1B (OpenVINO): Optimized for Intel hardware to provide near-instant planning.
  • 📜 Structured Outputs: Enforces strict JSON schemas for reliable desktop action sequences.
  • 🔄 Fallback Intelligence: Dynamic switching between GenAI and deterministic heuristics to ensure 100% uptime.
SENSORY FUSION

VLM & Multimodal

Fusing vision, memory, and desktop context into a single cohesive stream.

Visual Scene Understanding

Moondream integration allows OSCAR to "see" your workspace, identify objects, and read physical text through the webcam.

Multimodal Routing

Intelligently routes queries: "What is this?" (Vision VLM) vs "Open Chrome" (Direct Action) vs "Find my emails" (Screenpipe Memory).

Key Capabilities

  • 🔄 Seamless Fallback Engine: Intelligently switches between rapid active-window macros, lightweight heuristic parsing, and the GenAI planner to eliminate latency.
  • ✋ Non-blocking Hardware Loop: Interact solely via webcam. Hands-free and mouse-free operation enabled by asynchronous action queues.
  • 🕰️ Screenpipe Memory: Integrated retrospective lookups. OSCAR queries a local SQLite OCR database to recall what was on your screen hours ago.
  • 🛠️ App-Aware Command Macros: Knows what window is under your cursor. Commands like 'scroll down' immediately execute without bogging down the LLM.

Tech Stack

Models & AI

  • 🧠 Llama 3.2 1B: LLM optimized via OpenVINO.
  • 👁️ Moondream: VLM for visual scene analysis.
  • 👂 Faster-Whisper: Efficient local transcription.
  • 🗣️ Piper: Low-latency neural speech synthesis.

Core Infrastructure

  • 💻 Python 3.13: High-performance async runtime.
  • 🖼️ MediaPipe: Real-time hand/face tracking.
  • 🗄️ Screenpipe: Retrospective memory (SQLite/OCR).
  • ⚙️ PyAutoGUI: Cross-platform desktop automation.
